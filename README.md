### ⚡ Engineering Domains & System Architecture
*Click any domain below to inspect the underlying protocols, architectural patterns, and implementation stacks.*

<details open>
<summary><b>📱 Cross-Platform & Native Mobile Engineering (Android / Desktop / iOS)</b></summary>
<br/>

- **Flutter & Dart Ecosystem:** Engineered modular production applications using **Clean Architecture**, **Riverpod** for reactive state management, **GoRouter** for deep-linked navigation, and custom adaptive desktop/mobile container systems.
- **Native Android (Kotlin):** Built high-security native applications and SDKs utilizing **Jetpack Components**, **Dagger Hilt** dependency injection, **Coroutines & Flow**, and **Room Database**.
- **On-Device Cryptography & Storage:** Hardened mobile data layers using **SQLCipher** database encryption, **EncryptedSharedPreferences**, and hardware-backed **Android Keystore** cryptographic keys.
</details>

<details>
<summary><b>💳 FinTech, Payment Terminals (POS) & Financial Protocols</b></summary>
<br/>

- **EMV & Contactless Kernels:** Deep implementation experience with **EMV Level 2/3** card processing, APDU command flows, TLV tag parsing, **Single Tap** contactless payment pipelines, and **Mastercard / Visa** certification test suites.
- **Financial Messaging & Security:** Designed and debugged **ISO 8583** financial transaction message structures, secure PIN block handling, and **PCI-DSS** compliant terminal workflows.
- **POS App-to-App Ecosystems:** Built IPC and intent-driven SDK bridges allowing third-party retail apps to trigger, monitor, and settle transactions seamlessly on smart POS hardware.
</details>

<details>
<summary><b>⚙️ Distributed Backend Systems & Enterprise Microservices</b></summary>
<br/>

- **Spring Boot & Java Architecture:** Architected scalable microservices utilizing **Spring Boot**, **Spring Cloud (OpenFeign)** for declarative inter-service communication, and **Spring Data JPA / Hibernate**.
- **Asynchronous Messaging & Persistence:** Designed fault-tolerant event-driven pipelines using **RabbitMQ** message brokers and optimized complex relational schemas on **Microsoft SQL Server**.
</details>

<details>
<summary><b>🖨️ Hardware Integration, Document Archiving & AI Automation</b></summary>
<br/>

- **Hardware Scanner Bridges:** Engineered local background services and REST daemons that bridge web/desktop clients directly to enterprise hardware scanners (**Kodak**, **Canon**) via **TWAIN** and **WIA** driver protocols.
- **AI-Augmented Engineering & Automation:** Deployed local GPU-accelerated LLM inference servers (**Ollama / Qwen Coder**), spec-driven development pipelines, and automated **Python** monitoring bots with real-time **Telegram** webhook integrations.
</details>
